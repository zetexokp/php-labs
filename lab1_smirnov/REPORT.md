# Лабораторная работа № 1

Тема: Настройка среды разработки и создание приложения «Бюджет поездки».

Автор: Smirnov Vladislav  
Группа: IAFR2403

Среда: XAMPP.
Интерпретатор: `C:\xampp\php\php.exe`.
Версия PHP: 8.3.36.
Локальный сервер: встроенный сервер PHP, адрес `http://localhost:8000/`.

Структура проекта

`data.php` - сведения о поездке, константа валюты и массив расходов
`functions.php` - функции расчёта суммы, стоимости на человека, статуса бюджета и обработки массива
`index.php` - HTML-страница и вывод результатов

Выполненные проверки

1. Бюджет больше расходов - выводится остаток - https://screenrec.com/share/Vl8xMLtAD2
2. Бюджет равен расходам - выводится сообщение о полном использовании - https://screenrec.com/share/J57ch3ZE6L
3. Бюджет меньше расходов - выводится сумма превышения - https://screenrec.com/share/zFiEmwl0Vq
4. Участников 0 - деление не выполняется, выводится сообщение об ошибке - https://screenrec.com/share/FUQNcyDJ2L
5. Нет расходов от 1000 MDL - выводится сообщение об отсутствии записей - https://screenrec.com/share/ChPdcEzJ8e
6. Массив расходов пуст - общая сумма равна 0, самый большой расход отсутствует - https://screenrec.com/share/HYjPN4V9WM

Результат для выбранной поездки
- Направление: поездка в Брашов.
- Количество участников: 4.
- Бюджет группы: 7200 MDL.
- Общая стоимость: 7050 MDL.
- Стоимость на человека: 1762.50 MDL.
- Остаток бюджета: 150 MDL.
- Самый большой расход: гостиница - 2800 MDL.
